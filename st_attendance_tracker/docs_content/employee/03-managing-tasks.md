# Managing Your Tasks

After you check in, each task row has the controls described here. Use them as you work so your record is accurate when you check out.

![Task rows grouped by project](/assets/st_attendance_tracker/docs/c_checkin_full.png)

## Task row controls

| Control | What it does |
|---------|--------------|
| **Round checkbox** | Marks the task done. The text is crossed out |
| **Status** menu | *Completed*, *In progress* or *Pending* |
| **Est.** | Your estimate, such as `1h 30m` or `45m` |
| **Actual time** | Time actually spent. Fill this in when you finish |
| **Add remark** | Opens a notes field. Use it to explain delays or results |
| **Attach** (paperclip) | Upload one or more files to the task |
| **Carry forward** | For unfinished tasks. Untick it to drop the task instead of carrying it to tomorrow |
| **Repeat next day** | Appears when a task is done. Tick it to get a fresh copy on your next working day |
| **Move to backlog** (list icon) | Takes the task off today and puts it in your Task Backlog |
| **x** | Removes the task |

Descriptions are editable in place. Click the text and type.

## Time format

Type times as `1h 30m`, `45m` or `2h`. A bare number is read as minutes. Hours are totalled in the top strip and in your history.

## Projects

Tasks sit under a project folder. Click a project header to collapse or expand it. The header shows the number of tasks and how many are completed.

## Views

Once you have checked in, switch between **Detailed View** (every control visible) and **Concise View** (a compact list) with the buttons above the task list.

## Keyboard shortcuts

| Keys | Action |
|------|--------|
| **Shift+T** | Add a task |
| **Shift+P** | Add a project |

## Carried tasks

Tasks you do not finish are carried to the next working day automatically and show *Carried* with a day counter. A high counter means the task has been open for many days, so finish it, move it to the backlog, or drop it.

## Locked tasks

Tasks on past days, and all tasks after you check out, are locked. You cannot change their status or time.
