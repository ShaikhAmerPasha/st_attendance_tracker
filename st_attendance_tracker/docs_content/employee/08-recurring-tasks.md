# Recurring Tasks

Templates that put the same task on your Daily Check-in automatically, so you never retype it.

![Recurring Tasks, Classic design](/assets/st_attendance_tracker/docs/c_recurring.png)

## The list

Each template shows its title, project and estimate, a status badge (**Active** or **Inactive**), the days it repeats on (for example *Mon Tue Wed Thu Fri*, or *Every day*), and two buttons: **pencil** to edit and **bin** to delete.

## Create a template

1. Press **Add recurring task**.

![Add recurring task dialog](/assets/st_attendance_tracker/docs/c_recurring_new.png)

2. Fill in the form:
   - **Task description \*:** for example *Daily Scrum Standup*.
   - **Project name** (optional).
   - **Estimated time** (optional): `1h 30m`, `45m`.
   - **Repeats on:** tick **Mon–Sat**. Leave all unticked for a **daily** task.
   - **Active:** untick to pause it without deleting.
3. Press **Save**.

## Change or stop a template

- Press the **pencil** to change days, estimate or text.
- Untick **Active** to pause a template. Tick it again to resume.
- Press the **bin** to delete it for good.

## How it works

On each matching day the task is added to **Recurring** on your Today page with a *Recurs* badge. You can adjust the estimate, mark it done and record time like any other task.

## Tips

- Use recurring tasks for stand-ups, daily reading, reports and weekly reviews.
- Pause rather than delete if you may need a template again.
